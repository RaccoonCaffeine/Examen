# Bookers-Django-Catalogo

**Catálogo de libros con Django + Bootstrap 5 + AJAX. Proyecto examen transversal.**

## Stack

| Tecnología | Versión | Uso |
|:------------|:---------|:----|
| Django | 4.1 | Backend framework |
| SQLite | - | Base de datos |
| Bootstrap | 5 | Frontend y componentes UI |
| jQuery | 3.7 | Manipulación del DOM |
| AOS | - | Animaciones al scroll |
| SweetAlert2 | - | Alertas y diálogos modernos |
| Pillow | - | Procesamiento de imágenes |

## Funcionalidades

- CRUD completo de libros, autores y categorías
- Búsqueda dinámica con AJAX
- Carga de imágenes con `ImageField`
- Interfaz responsive con Bootstrap 5
- Animaciones con AOS (Animate on Scroll)
- Alertas interactivas con SweetAlert2

## Instalación

```bash
git clone https://github.com/RaccoonCaffeine/Bookers-Django-Catalogo.git
cd Bookers-Django-Catalogo
py -m venv myvenv
.\myvenv\Scripts\activate
pip install -r requeriments.txt
py manage.py runserver
```

Abrir [http://127.0.0.1:8000](http://127.0.0.1:8000)
