# BookersDjangoCatalogo

Catalogo de libros digital con Django 4 + Bootstrap 5 + AJAX.

---

## Stack Tecnologico

| Tecnologia | Version | Proposito |
|:-----------|:--------|:----------|
| **Django** | 4.1.2 | Framework web backend |
| **SQLite** | built-in | Base de datos relacional |
| **Bootstrap** | 5 | Framework CSS responsivo |
| **jQuery** | 3 | Manipulacion DOM |
| **AOS** | latest | Animaciones scroll |
| **SweetAlert2** | latest | Alertas modernas |
| **Pillow** | 10.4.0 | Procesamiento de imagenes |

## Funcionalidades

- CRUD completo de libros, autores y categorias
- Relaciones Foreign Key entre modelos
- Carga de imagenes con ImageField
- Busqueda asincrona con AJAX
- Interfaz responsiva con Bootstrap 5
- Animaciones con AOS
- Alertas interactivas con SweetAlert2
